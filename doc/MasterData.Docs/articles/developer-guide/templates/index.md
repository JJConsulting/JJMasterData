# Templates

Use Liquid/HTML templates when a grid cell or an action needs content composed from record values. Choose the guide for the rendering context: grid templates receive the current record's values, while template actions expose query results through `DataSource`.

- [Grid templates](grid-templates.md): Customize field values rendered in grid cells.
- [Template actions](template-actions.md): Render action content from SQL result sets.

Both guides include a Liquid quick reference and explain the data available during rendering. See [Troubleshooting](../templates-troubleshooting.md) when investigating missing values or rendering issues.
