# Bootstrap

JJMasterData uses Bootstrap for its generated UI. Use these guides to compose server-rendered components, use the corresponding Razor Tag Helpers, or compile a custom stylesheet for the host.

- [Bootstrap Components](components.md): Render C# components and compose them with `HtmlBuilder`.
- [Bootstrap Tag Helpers](tag-helpers.md): Use alerts, cards, links, breadcrumbs, and validation summaries in Razor.
- [Custom Bootstrap](custom-bootstrap.md): Compile a Bootstrap Sass theme and configure JJMasterData to load it.

For field layout and shared assets, see [UI customization](../customizations/ui-customization.md).
